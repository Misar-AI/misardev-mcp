# MisarDev agents

Task-scoped agents built on the @misardev/mcp MCP server. Each bundles a subset
of the tools with the rules for using them safely.

| Agent | Purpose |
| --- | --- |
| `project-shipper` | Takes a project from template to a verified live deployment, checking the address before and the site after. |
| `release-guardian` | Watches builds and deployments, rolls a broken change back to a checkpoint, and redeploys only with approval. |
| `codebase-navigator` | Answers questions from the indexed codebase and the web, citing the files and sources it actually read. |

All of them require authentication — see https://docs.misar.io/dev/mcp. Generated by
`scripts/mcp/generate-distribution.mjs`; edit the product entry, not these files.
